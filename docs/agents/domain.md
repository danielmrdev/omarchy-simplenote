# Domain docs

This is a single-context repository.

Before exploring a topic, read the root `GLOSSARY.md` and relevant decisions
in `docs/adr/`, if they exist. Proceed silently if they do not; create them
only when terms or decisions are resolved.

Use glossary terms in issues, proposals, hypotheses, and tests. Flag conflicts
with existing ADRs explicitly rather than silently overriding them.
