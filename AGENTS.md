## Project

This project is an Omarchy plugin targeting Omarchy 4.5 and later. Use the
`omarchy-plugin-development` skill when designing, implementing, validating,
or preparing the plugin for publication.

The repository is currently private but intended to become public, and the
plugin is intended for the Omarchy plugin marketplace. Add links to the public
repository and marketplace listing when they exist. Publication requires
explicit user approval.
